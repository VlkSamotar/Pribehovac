# Příběhovač

Interaktivní generátor příběhů pro výuku programování v Pythonu. Cílem cvičení je naučit žáky pracovat se seznamy, cykly a základní manipulací s daty.

## Úrovně
- 🥉 1: Vytvoření základního rozhraní a seznamu `words`.
- 🥈 2: Dynamické generování tlačítek pomocí cyklu `for`.
- 🥇 3: Umístění a správa slov v seznamu.
- 💎 Bonus: Implementace interaktivity (klikání).

## 🧩 Struktura projektu
```text
main.py                 # Hlavní spouštěcí soubor (referenční řešení)
main_students.py        # Studentská verze s TODO a nápovědami
README.md               # Kompletní didaktický průvodce
LICENSE                 # MIT Licence
```

## 🚀 Jak projekt použít
Otevřete soubor `main_students.py` v libovolném IDE pro Python a postupujte podle TODO komentářů.

## 🎯 Co si uživatel osvojí
- Práce se seznamy (list) v Pythonu.
- Použití cyklu `for`.
- Základy práce s grafickou knihovnou `arcade`.

## ⚙️ Použité technologie / Požadavky
- Python 3
- Knihovna `arcade`
